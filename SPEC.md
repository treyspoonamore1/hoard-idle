# Hoard — build spec (v1)

An original idle/incremental phone game. You are a baby dragon growing a gold hoard.
Played on a Google Pixel 10 in Chrome, published as a claude.ai Artifact page.
**Core feel: number goes up and accelerates. Swiping, never tapping, gathers gold** (tapping hurts the player's fingers). Everything else is big buttons, and repeated buys use press-and-hold, never rapid tapping.

## Files and ownership

```
hoard/
  index.html      UI agent   page content (NO <!doctype>/<html>/<head>/<body> tags — the publisher wraps it). <title>, <meta>, fonts <link>, inline <style>, markup, <script src> tags in order
  js/data.js      ENGINE     static content tables + number formatter
  js/engine.js    ENGINE     all game rules, pure state functions, save/load, offline progress
  js/cave.js      CAVE       canvas scene + swipe input (coins, streak, gust, treasures, hoard, dragon)
  js/ui.js        UI         DOM panels, tabs, lists, modals, toasts, hold-to-buy
  js/main.js      UI         boot, game loop, autosave (localStorage + db), offline welcome-back, hot-reload hook
  dev.html        INTEGRATOR full HTML doc wrapping index.html for local testing (generated by tools/build-dev.mjs)
  tools/          INTEGRATOR / reviewers: build-dev.mjs, sim.mjs (headless balance sim), playtest.mjs (Playwright)
```

Script load order in index.html: `js/data.js`, `js/engine.js`, `js/cave.js`, `js/ui.js`, `js/main.js` — classic scripts (`<script src="js/x.js"></script>`, NOT modules), relative paths, no bundler, no external libraries.

All code shares one global namespace: `window.HOARD` (data.js creates it: `var HOARD = (globalThis.HOARD = globalThis.HOARD || {});`).
**data.js and engine.js must also run in Node** (`globalThis`, no DOM, no `window`, no `localStorage` access in engine) so `tools/sim.mjs` can `vm.runInThisContext` them for balance simulation. engine.js must never touch the DOM.

Plain modern JS (ES2020), no TypeScript. `'use strict'` inside an IIFE per file.

## Game time

`state.time` = accumulated game seconds. All timed effects use `state.time`, never wall clock. `state.savedAt` (epoch ms) is the only wall-clock value, used for offline progress.

## State shape (engine owns; everyone reads; only engine functions mutate, except cave.js visual-only state which lives in cave.js)

```js
{
  v: 1,
  gold: 0,            // spendable
  earnedRun: 0,       // gold earned since last Long Sleep (drives Legend)
  earnedAll: 0,       // lifetime
  tiers: [0,0,0,0,0], // minion counts (floats allowed): 0 Eggs, 1 Wyrmlings, 2 Drakes, 3 Wyverns, 4 Elder Dragons
  buildings: { digger:0, raid:0, mine:0, tower:0, well:0, moon:0 },
  upgrades: {},       // { upgradeId: true }
  rank: 1,            // Dragon Rank
  rankProgress: 0,    // missions claimed toward next rank
  missions: [],       // exactly 3 active: { uid, tpl, key, target, base, done:false }
  missionSeq: 0,      // increments; seeds deterministic mission generation
  cards: {},          // { cardId: copiesOwned }
  chests: 0,          // unopened treasure chests
  legend: 0,          // permanent prestige currency
  sleeps: 0,
  gust: 1,            // wing gust charge 0..1 (1 = ready)
  effects: [],        // [{ kind, mult, until }]  until = state.time seconds
  stat: { swipePx:0, coins:0, treasures:0, gusts:0, bestStreak:1, sleepsGold:0 },
  run: { coins:0, treasures:0, gusts:0, bestStreak:1, swipePx:0 }, // per-Sleep stats (missions use these)
  time: 0,
  savedAt: 0,
  settings: { haptics:true, reducedMotion:false, buyAmt:1 } // buyAmt: 1 | 10 | 'max'
}
```

## Content (data.js) — `HOARD.data`

### Minion chain (AdCom-style: each tier produces the tier BELOW it)
Units are bought with gold **plus** units of the tier below (consumed). Price per unit is flat (no exponential growth) so counts can get huge.

| i | id | name | buy cost | produces |
|---|----|------|----------|----------|
| 0 | egg | Eggs | 4 gold | nothing (spent on buildings and Wyrmlings) |
| 1 | wyrmling | Wyrmlings | 60 gold + 10 Eggs | 1 Egg / s each ("forage eggs") |
| 2 | drake | Drakes | 1,500 gold + 8 Wyrmlings | 0.2 Wyrmlings / s each ("raise") |
| 3 | wyvern | Wyverns | 60,000 gold + 8 Drakes | 0.1 Drakes / s each ("train") |
| 4 | elder | Elder Dragons | 3,000,000 gold + 8 Wyverns | 0.05 Wyverns / s each ("lead") |

Tier production milestones: owning 10 / 25 / 50 / 100 / 250 / 500 / 1000 (rounded-down count) each doubles that tier's output.

### Buildings (produce gold; cost = gold AND minions; both scale by owned count)
gold cost = base × 1.15^owned; minion cost = ceil(base × 1.10^owned).

| id | name | gold | minions | base gold/s | unlock rank |
|----|------|------|---------|-------------|-------------|
| digger | Kobold Diggers | 15 | — | 0.3 | 1 |
| raid | Raiding Parties | 140 | 15 Eggs | 2 | 2 |
| mine | Gold Mines | 1,800 | 4 Wyrmlings | 14 | 3 |
| tower | Alchemy Towers | 26,000 | 4 Drakes | 100 | 4 |
| well | Wishing Wells | 420,000 | 3 Wyverns | 800 | 5 |
| moon | Gold Moons | 9,000,000 | 2 Elder Dragons | 7,000 | 6 |

Minion tier i unlocks at rank i+1 (Eggs at rank 1, Wyrmlings rank 2, …, Elders rank 5).
Building milestones: owning 25 / 50 / 100 / 150 / 200 / 300 / 400 … (every 100 after 200) each doubles that building. (Feel pass: now 10 / 25 / 50 / 100 / 150 / 200 / 300 …, and Nest warmth multiplies building gold/s; see EXTENSIONS.md. Ember kilns keep 25 / 50 / 100 / 150 / 200.)

### Lair upgrades (one-time gold purchases; ~14; shown when affordable-ish: cost ≤ 3× current gold or already near unlock; hide bought ones)
Must include at least:
- `claws1..claws4` Sharper Claws I–IV: coin worth ×2 each (costs 100, 5k, 500k, 50M).
- `scales1..scales3` Golden Scales I–III: each coin also worth +1% / +2% / +3% of gold/s (base 0.5% — see Coins). Costs 1k, 200k, 40M.
- `broom1..broom3` Kobold Broom Crew I–III: auto-sweeper collects 0.5 / 1.5 / 4 coins/s for you (costs 500, 50k, 5M). Requires owning 10 / 50 / 100 Kobold Diggers to appear.
- `wings1..wings2` Bigger Wings I–II: gust recharge 45s → 30s → 20s (costs 2k, 1M).
- `gleam1` Hoard Gleam: treasures appear 30% more often (cost 25k).
- `spill1` Overflowing Hoard: coin spill rate ×1.5 (cost 300).
Engine exposes which ones are visible.

### Coins & swiping (values come from engine; physics/visuals from cave)
- Base spill: 2 coins/s appear in the cave (×upgrades), max 70 on screen; above the cap new coins merge value into existing ones (cave increments a coin's `value` multiplier).
- **coinWorth** = (clawsMult + (0.005 + scalesPct)·gps / legendMult) × cardMult(swipe) × effects(ember) × legendMult. (gps already includes legendMult, so it is divided out to apply Legend once; claws scale only the flat part.)
- **Stroke value**: just moving a finger across the cave also earns: every 120px of swipe path → `0.25 × coinWorth` (streak multiplier applies). This makes swiping always worth something.
- **Streak**: while the finger is down and moving ≥ 50 px/s (slow circles count), streak time accumulates; multiplier ×1 → ×2 at 1.5s → ×3 at 4s → ×5 at 8s → ×8 at 15s (×8 requires card or rank 4+; otherwise cap ×5). Lift finger or stay still > 0.7s: streak decays one level every 0.7s. Streak multiplies coin and stroke gold.
- **Wing Gust**: a fast flick (path ≥ 140px within ≤ 220ms, speed ≥ 1400 px/s) when `state.gust >= 1` collects every coin on screen and spawns a burst: ×3 on up to `C.gustBonusCoins` (8) of them, the rest at normal worth (so a full screen left for the gust never beats swiping over the coins), and always at least `gustFloorCoins` (6) coins. Also a visible "Gust" button for accessibility (single press — fine). Recharge per Bigger Wings.
- **Auto-sweeper** (Broom Crew): cave animates a small kobold broom collecting the oldest coin at sweepRate coins/s; worth coinWorth ×1 (no streak). If the cave is offscreen/hidden, engine still credits sweep gold in tick via `stats.sweepGps`. (To avoid double counting: cave asks engine `HOARD.engine.sweepCollect(state)` per swept coin; engine tick adds sweep gold ONLY when `state._caveActive` is false. cave.js sets `state._caveActive = true` each frame it runs; main.js sets it false while document hidden. `_`-prefixed keys are never saved.)

### Gleaming treasures (cave spawns, engine applies)
Spawn every 70–130s (÷ gleam/card bonuses), drift across the cave for 13s, collected when the swipe path crosses them (radius 36px). `HOARD.engine.grabTreasure(state)` picks a weighted kind and applies it, returns `{kind, title, text}`:
- `frenzy` (35%): gold/s ×7 for 30s.
- `lucky` (25%): instant gold = min(15% of current gold + 13, 900 × gps) — at least 50 × coinWorth.
- `ember` (20%): coin & stroke worth ×10 for 20s.
- `swarm` (12%): returns `{spawnCoins: 45}` — cave spawns 45 coins.
- `clutch` (8%): +10% of each unlocked minion tier (min +5 Eggs).

### Treasure cards (collection; 20 cards)
Rarity weights: common 62, rare 27, epic 9, legendary 2. Copies → level: level = number of thresholds reached in [1, 3, 6, 10, 15, 25, 40, 60, 90, 140] (level 0 = unowned). Effect strength scales with level. Each card targets one stat. Must include cards that boost: each of the 6 buildings (×(1+0.5·lvl)), each of the 5 minion tiers' production (×(1+0.5·lvl); Eggs card instead makes Eggs 4% cheaper per level, max 40%), coin worth, stroke value, gust gold, treasure frequency, frenzy duration, offline cap (+1h per level), streak (unlocks ×8 at level 1, +5% streak mult per level), global gold/s (legendary, ×(1+0.25·lvl)), Legend gain (legendary, +10%/lvl). Give each an evocative original name ("Crown of the Kobold King", "Ember Egg", "Moonlit Scale", "Tide Pearl", …), rarity, `target`, and a `describe(level)` text.

### Missions & Dragon Rank (AdCom-style)
- 3 active missions at a time. Claiming one: +1 rankProgress, +1 chest, then a new mission replaces it.
- Rank r → r+1 needs `r + 2` claimed missions. Rank-up: +1 extra chest, toast, unlocks per tables. Max rank 12 for v1 (after 6, ranks just give chests and +5% gold/s each).
- Mission templates (pick ones relevant to unlocked content, deterministic from `missionSeq` with a simple seeded hash — no Math.random in generation): own N of building X; own N of minion tier i; earn N gold this Sleep; collect N coins this Sleep; reach a ×N streak; grab N treasures; use N gusts; reach N gold/s. Targets scale with rank so each mission takes ~1–4 minutes of active play early, longer later. Missions measure against current values (own N) or run stats (`state.run.*`) — "base" captures the run stat at creation so progress is incremental.
- Chests: `openChest(state)` grants 2 cards (3 at rank ≥ 6), returns card ids (weighted by rarity, deterministic seeding not required — Math.random allowed here and in treasures).

### Long Sleep (prestige)
- Available when `earnedRun ≥ 1e7`. Legend gained = floor( sqrt(earnedRun / 1e6) × (1 + 0.1·legendCardLvl) ) − nothing subtracted (legend is total from this sleep).
- Each Legend: +10% to all gold/s, coin worth, AND minion production (multiplicative factor `1 + 0.1·legend`).
- Sleep resets: gold, earnedRun, tiers, buildings, upgrades, rank (to 1), rankProgress, missions (regenerate), effects, run stats, gust (1), chests KEEP, cards KEEP, legend += gained, sleeps += 1. Also gives 1 bonus chest per sleep.
- Target pacing: first Long Sleep after ~45–75 minutes of mixed active/idle play. Second sleep noticeably faster.

### Offline
On load, `offline(state, seconds)` with seconds = clamp((now − savedAt)/1000, 0, capHours·3600) where capHours = 8 + card bonus. Simulate in ≤ 200 sub-steps (chain is polynomial; sub-stepping keeps it accurate). Effects do not run offline (clear expired). Returns `{seconds, gold, minions:[...gained per tier]}`. Main shows a "While you slept…" modal if seconds ≥ 60.

## Engine API — `HOARD.engine` (exact names; everyone codes against these)

```js
newState()                         -> state
deserialize(json|object|null)      -> state   // fills defaults, tolerates garbage, never throws
serialize(state)                   -> string  // JSON, omits _-prefixed keys
stats(state)                       -> { gps, coinWorth, strokeWorth, spillRate, sweepRate, sweepGps,
                                         gustCooldown, gustWorthMult, treasureInterval:[min,max],
                                         tierRates:[eggs/s, wyrm/s, drake/s, wyvern/s, 0],   // net gain per second of each tier
                                         buildingGps:{id:gps}, maxStreak, offlineCapHours,
                                         legendMult, frenzyActive, emberActive }
tick(state, dt)                    // dt seconds (caller clamps ≤ 1); production, gust recharge, effect expiry, missions done-flags, sweep credit when !_caveActive
earn(state, amount, source)        // adds to gold, earnedRun, earnedAll; source: 'coin'|'stroke'|'gust'|'sweep'|'treasure'
coinCollected(state, n, streakMult, valueMult=1) -> gold   // credits n coins (each coinWorth*streakMult*valueMult), updates stat/run.coins
strokeCollected(state, px, streakMult)            -> gold   // credits stroke gold for px of path, updates swipePx
sweepCollect(state, valueMult=1)                  -> gold
noteStreak(state, mult)            // updates bestStreak stats
gustReady(state) -> bool ; useGust(state) -> bool  // consumes charge, counts stats; cave then calls coinCollected with gust mult
grabTreasure(state)                -> { kind, title, text, spawnCoins? }
// buildings
buildingCost(state, id, n)         -> { gold, minionTier: -1|i, minions }
buildingMax(state, id)             -> integer affordable count (cap 10000)
buyBuilding(state, id, n)          -> bool
// minions
tierCost(state, i, n)              -> { gold, prevTier: -1|i-1, prev }
tierMax(state, i)                  -> integer (cap 1e15)
buyTier(state, i, n)               -> bool
// upgrades
upgradeList(state)                 -> [{ id, name, text, cost, bought, visible, affordable }]
buyUpgrade(state, id)              -> bool
// unlocks
isUnlocked(state, kind /*'building'|'tier'|'sleep'*/, idOrIndex) -> bool
nextMilestone(kind, owned)         -> integer next milestone count or null
// missions
missionInfo(state, idx)            -> { title, cur, target, frac, done }
claimMission(state, idx)           -> { ok, rankUp:bool, chests:int }
rankNeed(state)                    -> missions needed for next rank
// cards
openChest(state)                   -> [cardId,...] (empty if no chests)
cardInfo(state, cardId)            -> { id, name, rarity, copies, level, nextAt|null, text }
// prestige
legendOnSleep(state) -> number ; canSleep(state) -> bool ; sleep(state) -> legendGained
// offline
offline(state, seconds)            -> { seconds, gold, minions:[5] }
// events (engine emits; UI listens)
on(name, fn) ; emit(name, payload)  // names: 'rank'(rank), 'mission'(idx), 'chest'(cards), 'treasure'(result), 'sleep'(gained), 'unlock'({kind,id,name}), 'milestone'({kind,id,count})
```
All functions are defensive: unknown ids → false/zero, never throw, never produce NaN/Infinity in state (guard every arithmetic result; clamp huge numbers at 1e300).

`HOARD.fmt(n)` (data.js): < 1,000 → integer with no decimals unless < 10 and non-integer (one decimal); then 1.23K, 12.3K, 123K, M, B, T, Qa, Qi, Sx, Sp, Oc, No, Dc; ≥ 1e36 → `1.23e36`. `HOARD.fmtRate(n)` → fmt + "/s". `HOARD.fmtTime(sec)` → "2h 14m" / "3m 05s" / "12s".

## Screen layout (portrait phone, 412×915 CSS px Pixel 10 ≈ 412×923; must also work 360–480 wide and on desktop centered at max-width 520px)

One-screen app: `html, body { height: 100% }`, no page scroll, `overscroll-behavior: none`, `touch-action: none` on the cave (so swipes never scroll), `user-select: none`.

```
┌──────────────────────────────┐
│ GOLD 1.23M      [⚙]           │  top bar: big gold number (display face), gold/s below, Legend ×bonus chip if legend>0
│ +4.5K/s   ×3 streak chip      │  active effect chips (Frenzy 0:23, Ember)
├──────────────────────────────┤
│                              │
│        CAVE CANVAS            │  ~42% of height (min 260px). Swipe here.
│   coins, hoard pile, dragon,  │  Gust charge ring button bottom-right of cave
│   treasures drifting          │  floating "+1.2K" numbers
├──────────────────────────────┤
│ PANEL (scrolls internally)   │  content of active tab
│                              │
├──────────────────────────────┤
│ Lair  Brood  Quests  Hoard  Sleep │ tab bar (safe-area bottom padding); badges (e.g. claimable mission count, unopened chests)
└──────────────────────────────┘
```

Tabs:
- **Lair**: buy-amount toggle (×1 / ×10 / Max), visible upgrades (cards with name, effect text, cost, buy button), then buildings list: name, owned count, gold/s each & total, next milestone progress bar ("42/50 → ×2"), cost line (gold + minion cost; unaffordable part in muted/red), Buy button (press-and-hold repeats: first repeat after 400ms, then every 90ms, accelerating to 40ms). Locked buildings show one teaser row "Reach Dragon Rank 3 to unlock Gold Mines".
- **Brood**: minion chain tiers top (Elders) to bottom (Eggs) or bottom-up — show chain arrows ("each Drake raises 0.2 Wyrmlings/s"), count, net rate, cost, Buy (hold-to-buy), milestone bar.
- **Quests**: Dragon Rank header with progress pips (rankProgress/rankNeed), 3 mission cards (title, progress bar, Claim button when done), chest counter with "Open chest" button → chest modal reveals cards one by one with rarity color.
- **Hoard** (collection): grid of 20 cards (owned show name, rarity, level, copies toward next; unowned are silhouettes "???"), tap a card for detail sheet.
- **Sleep**: explains Long Sleep, shows Legend you'd gain now, current Legend & its bonus, requirement progress (earnedRun / 1e7), Sleep button → in-page confirm sheet (NO window.confirm). Also settings section: haptics toggle, reduce motion, "Copy save" (navigator.clipboard.writeText in click, fallback select textarea), "Load save" (paste into textarea), "Start over" (two-step in-page confirm).

Buttons ≥ 44px tall. Press-and-hold uses pointer events (pointerdown/up/cancel/leave), never click spam.

## Visual identity (deliberate single dark theme — a cave at night lit by gold)

- Single-theme on purpose: define tokens on `:root` with `color-scheme: dark`; no light theme blocks. Set `body` background explicitly.
- Palette (tokens): deep cave basalt with a cool blue-violet bias (not pure black), e.g. `--cave:#16131f`, `--rock:#221d2e`, `--rock-2:#2d2640`, `--gold:#f2b84b`, `--gold-hi:#ffe08a`, `--ember:#e8633a` (warnings/frenzy), `--moss:#7fc29b` (affordable/success), `--ink:#efe6d6` (text), `--ink-dim:#a59cb3`. Rarity: common `#b8b0c4`, rare `#6fb0ff`, epic `#c27cff`, legendary `--gold-hi`.
- Type: display `"Grenze Gotisch"` (Google Fonts; gold numbers and headings — the big gold total uses it), body `"Alegreya Sans"` (400/500/700) with fallbacks `system-ui, sans-serif`; numbers use `font-variant-numeric: tabular-nums`. One `<link>` to fonts.googleapis.com with `display=swap`.
- No emoji anywhere. Icons, if any, are small inline SVG drawn with currentColor.
- Cards/panels: rock-textured surfaces via subtle gradients; restrained radius (6–10px), not on everything. Buy buttons gold when affordable, dim when not.
- Respect `prefers-reduced-motion` and the in-game reduce-motion setting (fewer particles, no screen shake).

## Artifact page contract (index.html)
- First lines: `<title>Hoard</title>`, `<meta name="claude:viewport-fit-sides" content="cover">`, fonts link, `<style>`.
- Side gutters use `padding-left: max(16px, env(safe-area-inset-left, 0px))` / right likewise on the outer wrapper (cave canvas may run edge-to-edge inside its own band). Tab bar fixed at bottom adds `env(safe-area-inset-bottom, 0px)`.
- No alert/confirm/prompt. Wrap every localStorage access in try/catch.
- Capabilities declared at publish: `{ db: {}, user: {} }`. In main.js: `const use = window.claude?.use; if (use) { const db = await claude.use('db'); const user = await claude.use('user'); const id = user && await user.id(); }` — cloud save doc: `db.collection('data/users/' + id).doc('save')` storing `{ json: serialize(state), savedAt }`. Load: take whichever of localStorage / cloud has the newer `savedAt`. Cloud write at most every 60s and on `visibilitychange`→hidden, only if changed, one write at a time (await), never on load. Everything works with no `window.claude` at all (local file).
- localStorage key `hoard.save.v1`, write every 10s and on visibilitychange hidden / pagehide.
- Hot reload: `window.claude?.hot?.snapshot?.(() => HOARD.engine.serialize(state))`; boot via `window.claude?.hot?.ready ? window.claude.hot.ready(start) : start(window.claude?.hot?.data ?? null)`; `start(data)` uses `data` (string or object) if present, else the save.
- Vibration: `navigator.vibrate` wrapped in try/catch, only if settings.haptics; short pulses (8–15ms) on streak level-up, treasure grab, gust; never continuous.

## Cave scene (cave.js) — `HOARD.cave`

```js
HOARD.cave.init(canvasEl, getState)  // getState() returns live state object
HOARD.cave.frame(dt)                 // called by main loop each rAF; updates+draws; sets state._caveActive = true
HOARD.cave.resize()                  // DPR-aware (cap DPR 2.5)
HOARD.cave.gust()                    // triggered by the Gust button (same as flick)
HOARD.cave.onFloat = null            // optional hook
HOARD.cave.streak()                  // -> current streak multiplier (UI top bar chip)
```
- Draw: dark cave with layered stalactite silhouettes (procedural, seeded, computed once per resize into an offscreen canvas), ambient gold glow; hoard pile at bottom center whose size grows with log10(gold+1) (stacked coin ellipses, a few gems); a small original baby dragon (procedural canvas shapes: curled body, wing, glowing eye that blinks and follows the swipe a little) resting on the pile; coins = small gold ellipses with a shine, spill from the top/sides, bounce, settle; swipe trail = glowing gold ribbon that fades; floating gain numbers (`+1.2K`, batched per 150ms so not hundreds of labels); streak meter arc near the finger or top-left of cave ("×3"); gust = whoosh lines + all coins fly to the hoard; treasure = rotating glinting object (goblet/crown/ring drawn procedurally) drifting with a sparkle trail, plus a short banner on grab (cave draws title; UI also toasts via engine event).
- Input: pointer events on the canvas (pointerdown/move/up/cancel, `setPointerCapture`), use coalesced events when available, segment-vs-circle hit tests for coins (radius ~30px) and treasures (36px). Never require taps. A single tap does nothing harmful.
- Performance: ≤ 70 coins, ≤ 120 particles, object pools, no per-frame allocation in hot loops, 60fps on phone.

## Quality bar
- No console errors. No NaN/undefined rendered. Numbers update smoothly (top bar every frame; lists ≤ 5×/s and only the changed text).
- Fun first 60 seconds: first Kobold Digger affordable within ~15 s of swiping; first upgrade within ~1 min; rank 2 within ~3–4 min.
